# 11–12 – Land-cover training data in QGIS

Digitizing land-cover training polygons for a supervised classification on 20 cm true orthophotos
(RGB and colour-infrared) of Berlin.

| File | Content |
|---|---|
| `HandClass.qgz` | QGIS project |
| `Digitized ver2.gpkg`, `TomDigitized.gpkg`, `Tom-Training.gpkg` | digitized training polygons |
| `Tom.gpkg` | fishnet grid over the training area |

**Data:** the two orthophotos (`truedop20rgb/cir_berlin_training.tif`) via `get_data.R` or `tools/download_data.*`.
