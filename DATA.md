# Data sources

The input data is not stored in git but attached to the
[`data-v1.0` release](https://github.com/toihr/Advanced-Remote-Sensing-Exercises/releases/tag/data-v1.0).
It is redistributed here only to make the exercises reproducible. All rights remain with the original providers –
please cite them and respect their terms when reusing the data.

| Dataset | Used in | Provider / source | Terms |
|---|---|---|---|
| DWD climate normals 1961–1990 / 1981–2010, station list | 01 | [Deutscher Wetterdienst – Climate Data Center](https://opendata.dwd.de/climate_environment/CDC/) | [DWD open data](https://www.dwd.de/EN/service/copyright/copyright_node.html) (CC BY 4.0) |
| SRTM 1 Arc-Second Global DEM (`n21_w012`, `n48_e008`) | 02, 03 | NASA / USGS, via [EarthExplorer](https://earthexplorer.usgs.gov/) | Public domain |
| Monthly station temperatures Baden-Württemberg | 03 | DWD, prepared for the course | DWD open data |
| Municipal boundaries (`AX_KommunalesGebiet`, ALKIS) | 03 | Landesamt für Geoinformation und Landentwicklung Baden-Württemberg | Open data (dl-de/by-2.0) |
| Sentinel-2 L1C / L2A scenes and subsets | 04, 05 | [Copernicus / ESA](https://dataspace.copernicus.eu/) | Free, full and open – *contains modified Copernicus Sentinel data (2020, 2023)* |
| HyMap hyperspectral image Karlsruhe, tree-species reference data | 06 | Course material | Provided for teaching |
| EnMAP (simulated) image & biomass reference, Sonoma County | 07 | Course material (EnMAP-Box tutorial data) | Provided for teaching |
| Airborne laser scanning tiles `3dm_33_378/380_5815` | 08, 09 | [Geoportal Berlin](https://www.berlin.de/sen/sbw/stadtdaten/geoportal/) | dl-de/zero-2.0 |
| Forest stand inventory Berlin (`forst_bestand`) | 09 | Course material (Berliner Forsten) | Provided for teaching |
| TLS point cloud of a pine stand | 10 | Course material | Provided for teaching |
| True orthophotos 20 cm RGB / CIR (`truedop20`) | 11–12 | [Geoportal Berlin](https://www.berlin.de/sen/sbw/stadtdaten/geoportal/) | dl-de/zero-2.0 |

Derived products (classification maps, GeoPackages, `sonoma_rf.tif`, …) were created by me in the exercises.
